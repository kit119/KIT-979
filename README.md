# KIT-979 (Seven Steps)
KIT-979 (Seven Steps): Multi-script Chaṭṭha Saṅgāyana Pāḷi Tipiṭaka, Aṭṭhakathā, Ṭīkā, Anuṭīkā &amp; multi-language translations across 7 continents.

### Vision
**KIT-979 (Seven Steps)** is an open web project dedicated to studying and exploring Theravāda Buddhist texts grounded in the **Chaṭṭha Saṅgāyana Pāḷi** tradition, linking:
* **Tipiṭaka (Mūla — Canonical Texts)**
* **Aṭṭhakathā (Commentaries)** — including foundational works such as *Visuddhimagga*
* **Ṭīkā (Sub-commentaries)**
* **Anuṭīkā (Further Sub-commentaries)**

Inspired by the symbolism of the **Seven Steps**, the project aims to take deliberate, grounded steps toward making Pāḷi texts and translations accessible across cultures and languages across all seven continents.

### Pāḷi Scripts vs. Translations
* **Pāḷi Script Transliteration:** Preserves the original Pāḷi text while allowing readers to switch scripts—such as **Thai**, **Myanmar (Chaṭṭha Saṅgāyana)**, **Indic scripts**, **Sinhala**, and **Roman**—without altering the underlying Pāḷi wording.
* **Translations:** Designed to support parallel/side-by-side translations across multiple languages, starting with **Thai, English, Myanmar, Indic languages, Sinhala, Indonesian, Chinese, Russian, French, German**, and more over time.

### Project Status
Currently in **Early Development**—establishing repository structure, data schemas, script/text tooling, and an initial web reader prototype.

### Initial Roadmap
1. Define structured schemas linking **Tipiṭaka, Aṭṭhakathā, Ṭīkā, and Anuṭīkā**
2. Build Pāḷi multi-script transliteration and search capabilities
3. Create a clean parallel reading interface starting with **Thai** and **English**
4. Expand regional and international languages and open clear contribution workflows for developers, Pāḷi scholars, and translators

# KIT-979 (ก้าวเจ็ดก้าว)

> แนวคิดจากการก้าวเดินบนดอกบัวเจ็ดก้าวเมื่อครั้งประสูติ สู่การเผยแผ่พระธรรมคำสอนและคัมภีร์ทางพระพุทธศาสนาเถรวาทให้เข้าถึงผู้คนในเจ็ดทวีปอย่างเป็นระบบ เคารพต้นฉบับ และรองรับหลากหลายสคริปต์และภาษา

## วิสัยทัศน์และแนวคิดหลัก

โครงการ **KIT-979** มุ่งพัฒนาเว็บแพลตฟอร์มสำหรับศึกษาและสืบค้นคัมภีร์ทางพระพุทธศาสนาเถรวาท ครอบคลุม:
- **พระไตรปิฎก** (มูละ)
- **อรรถกถา**
- **ฎีกา**
- **อนุฎีกา** (รวมถึงคัมภีร์สำคัญอย่าง *วิสุทธิมรรค*)

โดยยึดต้นฉบับ **ฉัฏฐสังคีติบาลี (Chaṭṭha Saṅgāyana Pāḷi)** เป็นฐานหลัก และออกแบบระบบให้แยก **การแปลงสคริปต์บาลี (Transliteration)** ออกจาก **การแปลภาษา (Translation)** อย่างชัดเจน

## สคริปต์บาลีและภาษาที่ตั้งเป้าไว้ (Scripts & Languages)

### การแปลงอักษรบาลีข้ามสคริปต์ (Pāḷi Transliteration)
- อักษรไทย
- อักษรเมียนมา (ต้นฉบับฉัฏฐสังคีติ)
- อักษรเทวนาครี / ระบบอักษรในอินเดีย
- อักษรสิงหล (ศรีลังกา)
- อักษรโรมันปริวรรต (Roman / IAST / ALA-LC)

### คำแปลภาษา (Translations — ระยะเริ่มต้นและระยะขยาย)
- **ไทย** (ภาษาหลักของผู้ริเริ่ม)
- **เมียนมา** (บริบทฉัฏฐสังคีติ)
- **อินเดีย** (ภาษาในกลุ่มอินเดียตามความเหมาะสม)
- **ศรีลังกา** (สิงหล / บริบทวิสุทธิมรรค)
- **อังกฤษ** (ภาษาสากล)
- **อินโดนีเซีย, จีน, รัสเซีย, ฝรั่งเศส, เยอรมัน** และภาษาอื่นๆ ในเจ็ดทวีป

## แผนการดำเนินงานแบบ "ก้าวเจ็ดก้าว" (7-Step Roadmap)

1. **ก้าวที่ 1 — โครงสร้างคัมภีร์และฐานข้อมูล:** กำหนด Schema เชื่อมโยง พระไตรปิฎก ↔ อรรถกถา ↔ ฎีกา ↔ อนุฎีกา ในระดับย่อหน้า
2. **ก้าวที่ 2 — ระบบหลายสคริปต์ (Multi-Script):** พัฒนาโมดูลแปลงอักษรบาลีข้ามสคริปต์และระบบค้นหาคำบาลี
3. **ก้าวที่ 3 — หน้าอ่านคู่ขนาน (ไทย + อังกฤษ):** เปิดใช้งานโหมดอ่านเทียบเคียงบาลีกับคำแปลภาษาหลัก
4. **ก้าวที่ 4 — ขยายสู่ภูมิภาคเอเชียและคัมภีร์เฉพาะทาง:** เพิ่มเมียนมา สิงหล ภาษาในอินเดีย อินโดนีเซีย จีน และเชื่อมโยง *วิสุทธิมรรค*
5. **ก้าวที่ 5 — ขยายสู่ภาษาสากลเพิ่มเติม:** เพิ่มรัสเซีย ฝรั่งเศส เยอรมัน และภาษาอื่นๆ ตามความร่วมมือของชุมชน
6. **ก้าวที่ 6 — เครื่องมือช่วยศึกษา:** รองรับพจนานุกรมบาลี เลขอ้างอิงมาตรฐาน และลิงก์อ้างอิงตรงรายย่อหน้า
7. **ก้าวที่ 7 — เผยแพร่สู่ชุมชนเจ็ดทวีป:** จัดทำคู่มือการมีส่วนร่วม (Contributing Guide) และการตรวจทานคุณภาพคำแปลร่วมกับผู้รู้และนักพัฒนาทั่วโลก
